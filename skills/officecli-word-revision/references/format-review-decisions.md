## 原答纠错

| 原答中的过强或错误推论 | 作者核对与修正 |
|---|---|
| “正文从1起算”“各章/书目/附录另起页”是存档明文 | 存档明示罗马/阿拉伯制度；起算1与上述块新页属于本项目及既有profile约定 |
| `RestartNumberingAtSection` 默认False | 所选文档只说明设为False时续号，没有给出默认值；读取实际节设置 |
| 页眉章名变化就必需新节 | 还可评估STYLEREF等域；独立篇眉结构等节属性需要隔离时再分节。补充微软域类型文档不等于当前模板已原生验收 |
| WORD-SECTION证明全部OOXML层级，WORD-PAGEBREAK证明KeepWithNext | 所选VBA页面没有这些细节；工程解释另据本地实现及声明范围内的验证 |
| 所有文献引用都应改脚注，或脚注只能放解释 | 存档允许两种文献制度；解释性脚注可与作者年引用并存，脚注也可含文献域 |
| `ZOTERO_BIBL` 同样适用于NoteExpress/EndNote | 该域名是Zotero实现，不能套到其他软件的字段契约 |
| 删除缩进属性即可防止继承 | 指定表格须处理长度与字符两套显式零值，重开后核实际有效格式 |
| 三线表及最小行高都只是推荐 | 三线表及其表头样式是推荐；跨页行高最小值另列明确规则，来源矩阵已拆分 |
| 任何自动移动图表都不允许 | 用户已授权且对象/目标顺序明确时可按ID自动移动并验证；不擅自改变结果或论证关系 |
| Tag/Release或SHA“保证永久稳定、防篡改” | 固定commit和SHA识别版本、检测差异，不阻止所有修改或保证永久可获取；更强承诺须核实际不可变设置/归档 |
| 当前材料已确定“法定”附录清单 | 材料没有该清单，也不是法律依据；防外链误替代是工程建议，实际提交范围另据真实规定 |
| 引用文本匹配就能采用答案自报页码 | 补答多处自报页码错位；按本地12页映射纠正，原引与错误表述保留 |

例如，WORD-NUMBER实际在物理7—8页，DRAFT结构建议在10—12页，不能照抄补答中的“6页”“8页”等定位。原引匹配、论断支持、来源效力与页码定位分别核实。

## 无法唯一解释的两项：用户已作项目选择

学校存档对以下两项仍不足以推导唯一解释。NLM补问保留了这种不确定性，用户随后于2026-09-26明确选择：

| 设置 | 来源冲突或缺失 | 已确认的新稿默认 |
|---|---|---|
| 标题“占行”与段前/段后 | 章占6行却前2.5/后4；一级占4却前2.5/后2.5；二级占2却前1/后1；行距20pt | 保留字面换算：章前50/后80、一级前50/后50、二级前20/后20pt |
| 前置罗马大小写 | 存档举例I/II/III，未明确排斥小写 | 新稿统一大写I、II、III，即`upperRoman` |

对单行标题，简单相加得到150/120/60pt，而“占行”折算为120/80/40pt。此算式揭示解释冲突，**不预测实际页高**：页首段前间距、标题换行和Word分页行为仍须原生检查。

以上默认属于用户选择，不冒称学校唯一要求。RUC profile 1.1.0已记录来源；旧任务沿固定profile与文件继续，已冻结论文不重排。通用检查器的`roman`仍接受大小写；只有任务明确选择时才按具体大小写判定。

“是否每块分节”“是否每章右页开页”“是否强制正文陪图表”“多音姓字典”和实际附录许可，不是本任务的新阻塞项：按实际页级需求、版心及具体可靠题录处理；本轮公开范围和代码许可已有明确约定。没有具体实例时不新增确认流程。
