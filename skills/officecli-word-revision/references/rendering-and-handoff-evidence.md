# Rendered typography and shared native handoff

For the RUC profile, selected statistical tables consume the profile's zero first-line/hanging indentation and cell-alignment rules. Explicitly zero all twelve length/character indent attributes. A cell containing Han text (including mixed text) is left aligned; Latin, numeric, formula, date and interval content is right aligned. Preserve empty-cell alignment, merged/nested structure and formula content. This applies only to `table_policy=explicit` selections or the opt-in `all_body_tables`; `report_only` leaves table XML unchanged. Verify the actual saved output and the installed profile as well as the source declarations.

Inspect the final Word PDF, not just the DOCX style name. A bibliography style with SimSun can still render as DengXian when theme attributes override direct fonts. The thesis adapter removes theme overrides when it assigns explicit run fonts and maps major/minor theme Latin and Hans/Hant fonts to the profile's declared defaults. This supports newly regenerated Zotero field runs; it does not justify manually editing citation display caches. Verify again after native refresh and reopen.

Headers and footers must explicitly zero all length and character indent properties (left/right/start/end/firstLine/hanging and their Chars forms). Merely centering a paragraph or deleting firstLineChars can inherit Normal's two-character indent; Word can materialize it as 420 twips and shift the PDF by about 10.5 pt. Test odd/even/first-page stories and portrait/landscape sections. Preserve intentional blank first-page stories. Measure against each section's actual text area, not page-width/2; outside page numbers follow the explicit page/section policy.

`scripts/rendered_document_qa.py --pdf FINAL.pdf --spec SPEC.json --output QA.json` checks actual PDF glyph fonts and bounded story positions. Each spec page declares `font_regions` with [left,top,right,bottom] boxes and accepted Han/Latin PostScript font names, and/or `stories` with exact text, box, alignment, text_area=[left,right] and tolerance_pt. List actual font aliases explicitly; do not whitelist a substitution merely to make the check pass. The report names inspected pages/regions; uninspected plots and layout still need visual review.

Equation snapshots retain the raw XML digest as evidence and use a separate projection for semantic comparison. The projection uses expanded namespace names, omits empty `w:lastRenderedPageBreak`, and ignores only the listed `w:rPr` font/size/language/kerning/proofing metadata. It preserves mathematical properties, bold/italic/superscript distinctions, operators, token text, structure and other attributes. Empty formatting wrappers are immaterial. Rendered glyphs still need review; this projection is not a proof of every font-dependent mathematical convention. Preserve original FAIL evidence and any reconciliation; never globally ignore XML differences or use equation counts as equality proof.

Native refresh acceptance includes field JSON, visible results, save/reopen and the exact Word-exported PDF. Macro return, HTTP 200, dirty state and nonempty PDF are intermediate facts. Bind export evidence to both the final input DOCX and output PDF hashes.

For shared operation use the multi-agent broker's `word-zotero` resource in addition to the native OS lock. A native handoff requires documents=0, windows=0, no modal, no pending, and Zotero currentDoc/currentWindow=false, backed by an original task-bound receipt. -1743 is sender-specific Apple Events denial: record documents UNKNOWN. AX zero windows is not a document count. A diagnostic handoff can be coordinated separately; it must not admit another write. Do not reset TCC, restart Word/Zotero or close foreign documents automatically.

Keep statistical model interpretation and NotebookLM calls in the parent workflow. This tool consumes their evidence, and cannot grant full reproduction or NLM acceptance.
